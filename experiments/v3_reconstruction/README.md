# v3 reconstruction

An independent reconstruction of the v3 experiments reported in the September
2026 DRR paper (`paper/drr-v3/ssrn-5285993-sep2026.pdf`, SSRN 5285993).

> This implementation is an independent reconstruction of the experimental
> procedures described in Woodyard (2026), using the documented mathematical
> definitions, simulation parameters, random seeds, and repository snapshot.
> The original execution scripts and machine-readable results were unavailable.
> Implementation choices not specified in the manuscript are explicitly
> documented as reconstruction assumptions. All reported replication results are
> generated by the reconstructed implementation and are not represented as
> recovered original outputs.

## What was lost

The original `run_study.py`, `run_spectral_excess.py`, `make_figures.py`,
`results/study.json` and `results/spectral_excess.json` were never committed
and could not be recovered. What survives is the manuscript text, the seeds
(20260925 and 20260926), abbreviated configuration hashes, the reported
environment, and repository commit `862c4f75e6092e3314eb786adcb9fa2a7ee3e779`.

## Files

- `protocol.json`: registered before any reconstruction run. It fixes the
  designs, every implementation assumption the manuscript leaves open
  (A1–A14), the paper values to compare against, the comparison rules and the
  scientific findings (F1–F12) with their decision rules.
- `amendments.md`: every change made after registration, with its reason.

The reconstruction code, runner and outputs are added in later commits, so the
history shows the protocol was fixed first.

## Rule

Reproducing the scientific findings matters more than matching the published
numbers. Nothing is tuned to recover the original tables. Differences are
reported as findings.
